# PySpark Learning Journey

This repository contains my hands-on learning notes, exercises, and notebooks focused on Apache Spark and PySpark.

## Overview

The goal of this learning folder is to build a strong foundation in big data processing using Python and Spark. It covers the essential concepts needed to work with large datasets, clean and transform data, aggregate information, and build machine learning models using Spark ecosystem tools.

## Topics Covered

- PySpark installation and setup
- Creating and using `SparkSession`
- Working with DataFrames
- Data filtering and transformation operations
- GroupBy and aggregate functions
- Handling missing values
- Working with Databricks
- MLlib and linear regression
- Basic analytics and data processing workflows

## Notebook Files

- `pyspark_installation.ipynb` - Setup and installation concepts for PySpark
- `pyspark_dataframes.ipynb` - Introduction to DataFrames and basic operations
- `pyspark_filter_operations.ipynb` - Filtering and conditional logic
- `pyspark_groupby_aggregated_functions.ipynb` - GroupBy and aggregation techniques
- `pyspark_handling_missing_values.ipynb` - Missing data handling in Spark
- `pysaprk_with_databricks.ipynb` - Databricks workflow basics
- `pyspark_mllib.ipynb` - MLlib fundamentals
- `pyspark_muti_linear_regression.ipynb` - Multi-linear regression using Spark ML
